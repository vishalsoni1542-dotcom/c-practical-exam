# Vowel or Consonant Using Switch

## 📌 Project Description

This C program takes a **character** from the user and checks whether the character is a **vowel or consonant** using a `switch` statement.

## 🚀 Features

* Accepts a character from the user.
* Checks both uppercase and lowercase vowels.
* Uses a `switch` statement.
* Displays whether the character is a vowel or consonant.

## 🛠️ Concepts Used

* `#include <stdio.h>`
* `main()` function
* Character input
* `switch` statement
* `case`
* `default`
* `printf()` and `scanf()`
* `break`

## ▶️ Example

### Input

```text
enter a character: A
```

### Output

```text
A is a vowel
```

### Input

```text
enter a character: B
```

### Output

```text
B is a consonant
```
