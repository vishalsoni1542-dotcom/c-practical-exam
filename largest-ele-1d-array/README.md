# Largest Element in Array

## 📌 Project Description

This C program takes the **size of an array** from the user, accepts all array elements, and finds the **largest element** present in the array.

It is a simple beginner-level program that demonstrates how to work with **arrays, loops, user input, and conditional statements in C**.

## 🚀 Features

* Accepts array size from the user.
* Creates an integer array.
* Takes input for all array elements.
* Compares the array elements.
* Finds the largest element.
* Displays the largest element.

## 🛠️ Concepts Used

* `#include <stdio.h>`
* `main()` function
* Arrays
* `for` loops
* `scanf()` and `printf()`
* `if` condition
* Variables and initialization
* Comparison operators
