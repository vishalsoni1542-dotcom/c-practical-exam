# Reverse a String

## 📌 Project Description

This C program takes a **string** from the user and reverses the string without using any library function.

It is a simple beginner-level program that demonstrates how to work with **strings, character arrays, loops, and string indexing in C**.

## 🚀 Features

* Accepts a string from the user.
* Finds the length of the string.
* Starts from the last character.
* Prints the string in reverse order.
* Does not use any string library function.

## 🛠️ Concepts Used

* `#include <stdio.h>`
* `main()` function
* Character Array
* Strings
* `scanf()`
* `while` loop
* `for` loop
* Array indexing
* `printf()`
