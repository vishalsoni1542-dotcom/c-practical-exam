# Square of Each Array Element Using Pointer

## 📌 Project Description

This C program takes the **size of an array** from the user, accepts all array elements using a pointer, and calculates the **square of each element** using pointer notation.

It is a simple beginner-level program that demonstrates how to work with **arrays, pointers, loops, and arithmetic operations in C**.

## 🚀 Features

* Accepts array size from the user.
* Creates an integer array.
* Uses a pointer to access array elements.
* Takes input using pointer notation.
* Calculates the square of each element.
* Displays the square of each element.

## 🛠️ Concepts Used

* `#include <stdio.h>`
* `main()` function
* Arrays
* Pointers
* Pointer Arithmetic
* Dereferencing
* `for` loops
* `scanf()` and `printf()`
* Multiplication
