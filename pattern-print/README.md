# Square Number Pattern

## 📌 Project Description

This C program prints a **square number pattern** using nested `for` loops.

In each row, the square of the row number is printed according to the row number.

## 🚀 Features

* Uses nested `for` loops.
* Calculates the square of each row number.
* Prints the square number multiple times in each row.
* Creates a number pattern from `1` to `5`.

## 🛠️ Concepts Used

* `#include <stdio.h>`
* `main()` function
* Variables
* `for` loops
* Nested loops
* Multiplication
* `printf()`

### Output

```text
1
4 4
9 9 9
16 16 16 16
25 25 25 25 25
```
